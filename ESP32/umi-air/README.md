# UMI项目

该项目在之前esp32代码的基础上做进一步改进，包括以下主要的改进点：

1. 无线方式通信方式：由wifi改为BLE低功耗蓝牙，使用一个esp32 s3作为蓝牙server端，将通过蓝牙协议接收到的数据通过rosserial的方式发送到主机

2. 硬件减少：去掉电位器摇杆，去掉霍尔编码器

3. 硬件增改：oled显示屏面积增大为之前的两倍，可以显示更多面积。增加编码器
